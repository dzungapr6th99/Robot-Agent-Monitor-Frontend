| Lệnh | Kết quả thực tế |
| --- | --- |
| `npm ci --no-audit --no-fund` | Đạt, cài 376 package |

4 test mới kiểm tra: gửi đúng payload và hiển thị 12 bước, Stop/Stopping, khóa
gửi khi ROS offline và backend trả 503, hiển thị lỗi backend thật khi status cũ
vẫn báo running. Hai bài thành công/Stop dùng VLA mock và ROS status mock; bài
hiển thị lỗi chỉ mock status cũ, để request tới backend Rust thật.

Lần chạy đầu thiếu browser, đồng thời runner lỗi Unicode console và dọn process;
đã sửa và chạy lại từ trạng thái sạch: 9/9 trong 24.6 giây. Kiểm tra bằng Python
socket sau test xác nhận port 18080 và 3100 đều đóng. Kết quả cuối ở
`robot-agent-monitor/.e2e-logs/results.txt`; log backend/frontend cùng thư mục.

## Còn vướng

Chưa kiểm chứng ROS publish, chuyển động Isaac Sim và Stop qua ROS thật.
Backend build feature ROS thất bại vì thiếu môi trường ROS được source. Cần VLA
server/checkpoint thật; hợp đồng hiện dùng POST `/infer`, quan sát joint position,
theo giả định trong kế hoạch. Cấu hình timeout ghi trong README và appsettings.

Báo cáo backend tại `../robot-agent-monitor-rust/REPORT-261117-4375.md` liệt kê
thay đổi Rust và kết quả chi tiết, gồm các test cũ cần tài nguyên ngoài workspace.
Phiên không có tool `write_report`, nên lưu báo cáo bằng file trong worktree.
